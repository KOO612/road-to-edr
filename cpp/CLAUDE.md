# C++ 한 달 집중 학습 계획 (개념 → 실습)

> **이 문서를 읽는 Claude Code에게:** 이 파일은 사용자의 C++ 학습을 한 달간 이끄는 **지시서이자 진도표**다.
> 아래 "Claude Code 운영 지침"을 먼저 읽고, 그 규칙대로 매 세션을 진행하라.
> 사용자의 최종 목표는 **Windows 엔드포인트/시스템 보안 SW 개발(백신·EDR·드라이버)로의 전환**이며,
> 따라서 C++ 학습도 "모던 C++ + 시스템/네이티브 관점"에 무게를 둔다.

## 0. 학습자 프로필 (맥락)

- 웹 Node.js 백엔드 1년 8개월 → 프로그래밍 기본기·논리는 있음
- C++ 의료진단 데스크탑 SW 6개월 경험은 있으나 체계가 없음 → **이번 학습은 완전 처음부터 체계적으로** 진행
- 목표: 엔드포인트 보안 SW 개발로 이직. 이후 Windows Internals·커널 드라이버로 진행 예정
- 즉, 이 한 달은 그 큰 로드맵의 **첫 블록(C++ 심화)**에 해당한다

## 0-1. 학습 환경 (확정)

- OS: **Windows** (확정)
- 컴파일러/IDE: **Visual Studio(MSVC)** 사용 중 (확정)
- 빌드: 초반엔 Visual Studio 프로젝트/단일 파일 → 중반부터 CMake
- 하루 투입: 평일 1.5~2시간 + 주말 더 여유 (주당 약 12~15시간)
- **C++ 수준: 완전 초보로 간주하고 처음부터 진행한다.** 6개월 경험이 있더라도 체계가 없다고 보고, 기초 개념도 건너뛰지 말고 설명한다. 사용자가 "이건 안다"고 하면 그때 빠르게 넘어간다.

## 1. Claude Code 운영 지침 (★ 매 세션 반드시 준수)

### 세션 시작 시
1. `PROGRESS.md` 파일이 있으면 읽어 현재 Day/진도를 파악한다. 없으면 생성한다(아래 템플릿).
2. 오늘 진행할 Day의 목표·개념·실습을 사용자에게 간단히 브리핑한다.
3. 사용자가 "이어서" 또는 특정 Day를 지정하면 거기서 시작한다.

### 개념 학습 진행 방식
- **설명을 넉넉하고 친절하게 한다 (사용자 선호).** 개념을 "정의 → 왜 필요한가 → 동작 원리 → 예시 → 흔한 실수" 순으로 풀어서 설명한다. 요약식으로 짧게 끊지 말고, 비유와 예시를 충분히 든다.
- 단, **한 번에 다 쏟아내지는 말 것.** 큰 개념은 작은 덩어리로 쪼개 설명하고, 덩어리마다 사용자가 이해했는지 **질문으로 확인**한 뒤 다음으로 넘어간다. (설명은 길게, 호흡은 끊어서)
- **모든 설명·자료·예시는 한국어로 한다 (사용자 선호: 영어 자료 X).** 영어 원문 링크나 영어 문서를 과제로 주지 않는다. 기술 용어의 영어 표기는 괄호로 병기하는 정도만 허용(예: 참조(reference)).
- Node.js/웹 백엔드 경험과 **비교·연결**해서 설명하면 이해가 빠르다 (예: "JS의 GC가 해주던 걸 C++에선 RAII로 네가 설계한다").
- 각 개념마다 **"왜 이게 보안 SW에서 중요한가"**를 한 줄이라도 덧붙인다.

### 실습 진행 방식 (★ 가장 중요)
- **절대 정답 코드를 먼저 통째로 주지 말 것.** 사용자가 직접 짜게 한다.
- 실습은 다음 순서로:
  1. 요구사항·힌트 제시 → 2. 사용자가 작성 → 3. 사용자가 코드 제출 → 4. **리뷰**(잘한 점 + 고칠 점 + 더 나은 방법) → 5. 필요시 개선 반복
- 사용자가 막히면 **답이 아니라 힌트를 단계적으로** 준다. 3단계 힌트 후에도 막히면 함께 풀되, 왜 그런지 설명한다.
- 코드 리뷰 시 체크: 메모리 안전성, RAII 적용, const 정확성, 네이밍, 예외 안전성, 불필요한 복사.

### 평가·피드백
- 각 Day 끝에 **체크 질문 2~3개**로 이해도를 점검한다. 통과 못 하면 다음 Day로 넘어가지 말고 보강한다.
- 주말(Day 6, 13, 20, 27 등)은 새 개념보다 **그 주 내용 복습 + 미니 프로젝트**에 쓴다.

### 진도 기록
- 매 세션 끝에 `PROGRESS.md`를 갱신한다: 완료한 Day, 막혔던 부분, 다음에 할 것, 복습 필요 항목.
- 사용자가 작성한 실습 코드는 `exercises/dayXX/` 폴더에 저장하도록 안내한다.

### ★ "학습한 내용 md로 요약해줘" 명령 처리 규칙
사용자가 **"내가 학습한 내용 md로 요약해줘"** (또는 비슷한 말)라고 하면 아래대로 동작한다.

1. **범위**: `notes/` 폴더에서 **가장 최근 요약 파일 이후**부터 지금까지 학습한 내용을 요약한다.
   - 이전 요약이 없으면(첫 요약이면) Day 1부터 현재까지 전체를 요약한다.
   - "마지막 기록 시점"은 가장 최근 요약 파일의 날짜/Day를 기준으로 판단한다. 애매하면 `PROGRESS.md`의 완료 Day와 대조한다.
2. **저장 위치·이름**: `notes/` 폴더에 `YYYY-MM-DD_dayXX-XX_요약.md` 형식으로 **새 파일**을 만든다. (기존 요약을 덮어쓰지 말 것)
3. **요약에 담을 내용** (한국어):
   - 다룬 기간/Day 범위
   - 핵심 개념 정리 (개념별 2~4줄, 코드가 꼭 필요하면 짧은 스니펫)
   - 직접 짠 실습과 거기서 배운 점
   - 막혔던 부분과 해결 방법
   - 아직 헷갈리는 것 / 복습 필요 항목
   - 다음에 이어갈 내용
4. **요약 후**: 방금 만든 요약 파일의 경로를 사용자에게 알려주고, `PROGRESS.md`에도 "최근 요약: (파일명)"을 기록해 다음 요약의 기준점으로 쓴다.
5. 요약은 **복습용**이다. 새로 가르치지 말고, 배운 것만 정리한다. 사용자의 언어(한국어)로 간결하되 빠짐없이.

### 금지/주의
- 진도를 사용자보다 앞서 끌고 가지 말 것. 사용자 페이스에 맞춘다.
- "이해했어?"에 그냥 "응" 하면, 가끔 **역질문**으로 진짜 이해를 확인한다.
- 커널·드라이버 같은 다음 단계 주제는 이 한 달 범위 밖이다. 궁금해하면 "다음 로드맵"이라고만 안내하고 본 궤도 유지.

## 2. 한 달 커리큘럼 (Day 1 ~ Day 28)

> 구성: 4주 × 7일. 평일 개념+실습, 토요일 복습+미니프로젝트, 일요일 휴식/버퍼(밀린 것 보강).

### Week 1 — C++ 기초 재정비 & 메모리 모델

- **Day 1 — 환경 확인 & 첫 프로그램 & 기본 문법 입문**
  - 개념(완전 초보 기준): Visual Studio에서 프로젝트 만들고 빌드·실행하는 법, `main` 함수, `#include`, `std::cout`/`std::cin`(출력·입력), 변수 선언, 세미콜론·중괄호 등 기본 문법, 주석
  - 추가 개념: 전처리 → 컴파일 → 링크가 무엇인지 (큰 그림만 쉽게)
  - 실습: Hello World 실행 → 이름을 입력받아 인사 출력 → 두 수를 입력받아 사칙연산 출력
  - 참고: 조건문(if)·반복문(for/while)이 처음이면 여기서 함께 짚고 넘어간다. 사용자가 이미 안다고 하면 빠르게 확인만.
- **Day 2 — 타입, 변수, 메모리 레이아웃**
  - 개념: 기본 타입 크기, 정수 오버플로, 부호/비부호, 스택 vs 힙, 변수 수명
  - 실습: sizeof 탐험, 스택/힙 할당 비교, 오버플로 재현해보기
  - 보안 포인트: 정수 오버플로·메모리 위치가 취약점의 출발점
- **Day 3 — 포인터와 참조**
  - 개념: 포인터, 참조, 주소 연산, 널 포인터, 댕글링 포인터, 포인터 vs 참조
  - 실습: 포인터로 값 교환(swap), 배열 순회를 포인터로, 댕글링 상황 재현
- **Day 4 — 배열, 문자열, C 스타일 vs std::string**
  - 개념: C 배열, 포인터 감쇠, C 문자열(널 종료), `std::string`, `std::string_view`
  - 실습: 간단한 문자열 처리기(길이/역순/검색) — C 스타일과 std 버전 둘 다
  - 보안 포인트: 버퍼 오버플로가 왜 C 문자열에서 터지는가
- **Day 5 — 함수, 오버로딩, 값/참조/포인터 전달**
  - 개념: 매개변수 전달 방식, const 참조, 반환값 최적화 개념, 함수 포인터 맛보기
  - 실습: 같은 기능을 값/참조/포인터로 각각 구현해 차이 체감
- **Day 6 (토) — 복습 + 미니프로젝트 #1**
  - 미니프로젝트: **CLI 계산기** 또는 **간단한 단어 빈도 세기** (파일 입력 → 처리 → 출력)
- **Day 7 (일) — 버퍼/휴식**

### Week 2 — 모던 C++의 핵심: RAII, 스마트 포인터, 클래스

- **Day 8 — 클래스 기초 & 생성자/소멸자**
  - 개념: 캡슐화, 생성자/소멸자, 멤버 초기화 리스트, this
  - 실습: 간단한 `Timer`나 `Logger` 클래스
- **Day 9 — RAII (★ 모던 C++의 심장)**
  - 개념: 자원 획득=초기화, 소멸자에서 해제, 왜 예외에 안전한가
  - 실습: `FileHandle` RAII 래퍼 (열기는 생성자, 닫기는 소멸자)
  - 보안 포인트: Windows HANDLE/리소스 누수를 RAII로 막는 게 네이티브 개발의 기본
- **Day 10 — 복사 vs 이동, Rule of 0/3/5**
  - 개념: 복사 생성자/대입, 이동 생성자/대입, Rule of 0/3/5, 얕은/깊은 복사
  - 실습: 동적 배열을 감싸는 클래스 만들어 복사·이동 직접 구현
- **Day 11 — 스마트 포인터**
  - 개념: `unique_ptr`, `shared_ptr`, `weak_ptr`, 소유권 개념, 순환 참조
  - 실습: raw 포인터로 짠 코드를 스마트 포인터로 리팩터링
  - 보안 포인트: use-after-free·이중 해제를 구조적으로 예방
- **Day 12 — const 정확성 & 참조 심화**
  - 개념: const 멤버함수, const 매개변수, constexpr 맛보기, 참조 수명
  - 실습: 기존 실습 코드에 const를 올바르게 전부 적용
- **Day 13 (토) — 복습 + 미니프로젝트 #2**
  - 미니프로젝트: **동적 문자열 클래스(간이 String)** — 복사/이동/RAII 전부 적용
- **Day 14 (일) — 버퍼/휴식**

### Week 3 — STL, 템플릿, 에러 처리

- **Day 15 — STL 컨테이너**
  - 개념: `vector`, `array`, `map`, `unordered_map`, `set`, 반복자, 언제 무엇을
  - 실습: 로그 라인들을 벡터에 담아 정렬·필터·집계
- **Day 16 — STL 알고리즘 & 람다**
  - 개념: `sort`, `find_if`, `transform`, `accumulate`, 람다 캡처
  - 실습: 알고리즘+람다로 데이터 파이프라인 짜기 (루프를 알고리즘으로 치환)
- **Day 17 — 템플릿 기초**
  - 개념: 함수 템플릿, 클래스 템플릿, 타입 추론, 왜 헤더에 두는가
  - 실습: 제네릭 `Stack<T>` 또는 `min/max/clamp` 템플릿
- **Day 18 — 에러 처리: 예외 vs 에러 코드**
  - 개념: 예외 메커니즘, 예외 안전성 보장 수준, 언제 예외가 부적절한가, `std::optional`/`expected` 개념
  - 실습: 같은 함수를 예외 버전과 에러코드 버전으로 작성해 비교
  - 보안 포인트: 커널·드라이버는 예외를 못 쓴다 → NTSTATUS 같은 반환값 패턴을 미리 체감
- **Day 19 — 열거형, 구조체, 비트 연산**
  - 개념: `enum class`, 구조체 패킹/정렬, 비트 플래그, 비트마스크
  - 실습: 권한 플래그를 비트마스크로 다루는 작은 모듈
  - 보안 포인트: 파일 포맷·권한·플래그 파싱에 필수
- **Day 20 (토) — 복습 + 미니프로젝트 #3**
  - 미니프로젝트: **간단한 로그 분석기** — 파일 파싱 → 컨테이너 집계 → 리포트 출력
- **Day 21 (일) — 버퍼/휴식**

### Week 4 — 동시성, 빌드 시스템, 종합 프로젝트

- **Day 22 — 멀티스레딩 기초**
  - 개념: `std::thread`, join/detach, 데이터 경쟁, `mutex`, `lock_guard`
  - 실습: 여러 스레드로 카운터 증가 → 경쟁 재현 → mutex로 수정
  - 보안 포인트: EDR 에이전트는 수집/처리 스레드가 동시에 돈다
- **Day 23 — 동기화 심화 & atomic**
  - 개념: `atomic`, condition_variable, 생산자-소비자, 데드락
  - 실습: **스레드 안전 큐**(생산자-소비자) — 미니 EDR의 이벤트 큐 축소판
- **Day 24 — CMake & 프로젝트 구조**
  - 개념: CMakeLists 기본, 타깃, 라이브러리 분리, 디버그/릴리스
  - 실습: 지금까지 코드를 CMake 멀티파일 프로젝트로 재구성
- **Day 25 — 디버깅 & 도구**
  - 개념: 디버거로 중단점/스텝/변수감시, 메모리 문제 진단, 주소 소독기(ASan) 개념
  - 실습: 일부러 버그 심은 코드를 디버거로 추적해 수정
- **Day 26 — 파일 I/O & 바이너리 다루기**
  - 개념: 텍스트/바이너리 스트림, 바이트 단위 읽기, 구조체로 바이너리 파싱
  - 실습: 작은 바이너리 파일의 헤더를 읽어 필드 출력 (다음 로드맵의 PE 파서 준비운동)
- **Day 27 (토) — 종합 프로젝트 (캡스톤)**
  - **미니 프로젝트: "프로세스/파일 정보 수집 CLI"**
