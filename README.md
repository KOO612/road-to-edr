# road-to-edr

Windows 엔드포인트 보안(EDR) 개발 역량을 쌓아 가는 학습 기록입니다.
C++ → Win32 유저모드 → 유저모드 미니 EDR → 커널 드라이버 순서로 진행하며, 읽은 것은 반드시 직접 짠 코드로 남깁니다.

- 시작: 2026-10-01
- 언어/환경: C++ (Visual Studio), Win32 API, WDK, Node.js(수집 서버)
- 커널 실습은 모두 VM의 테스트 서명 모드에서 진행합니다.

## Phase 개요

| Phase | 주차 | 내용 | 목표 |
| --- | --- | --- | --- |
| 0 | 1 | 환경과 진단 | 개발 환경, Git, VM, 현재 구현력 진단 |
| 1 | 2~8 | C++ 직접 구현력 | 재구현 훈련, 자료구조 직접 구현, 스마트 포인터·RAII |
| 2 | 9~13 | OS와 Win32 유저모드 | 프로세스·스레드·메모리·동기화, 서비스, 디버깅 |
| 3 | 14~20 | 유저모드 미니 EDR + 보안 기초 | ETW 행위 수집, 룰 엔진, 개인정보 패턴 탐지, 수집 서버 |
| 4 | 21~36 | 커널 드라이버 | WDF, IOCTL, 커널 콜백, 미니필터, WinDbg |
| 5 | 37~52 | 커널 포함 EDR + 리버싱 | 커널–유저 파이프라인, WFP, 자기보호, 최적화 |
