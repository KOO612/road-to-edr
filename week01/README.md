## 컴파일과 링크는 왜 나뉘어 있나
1. 전처리 (preprocessing)
- ```#include``` 는 헤더파일 내용을 그자리에 복사해 붙여 넣음
2. 컴파일 (compile)
- ```.cpp``` 파일을 기계어인 ```.obj```로 바꿈
3. 링크 (link)
- 여러 ```.obj```와 ```.lib```를 모아 함수 본문에 연결해 ```.exe```를 만듬

### 컴파일과 링크
컴파일 : 사람이 작성한 소스 코드를 프로세서가 이해할 수 있는 오브젝트 코드로 변경하는 과정
링크 : 여러 오브젝트 파일을 하나의 실행 파일로 묶는 과정

## 포인터
- 메모리 주소를 저장하는 변수

& : 피연산자의 주소를 읽어오는 주소 연산자

- 모든 포인터 변수의 크기는 같다

## 힙 영역
- 동적 할당된 변수 - 힙 영역
- 스택보다 큰 메모리 풀이라 크기가 큰 배열도 충분히 할당 가능
- 메모리를 해제하지 않으면 메모리 누수가 누적

## 포인터 주의점
- 포인터 역참조하기 전 유효한 메모리를 가리키는지 확인
- 할당된 메모리의 범위를 벗어나는 포인터 연산 피해야 함
- 할당 해제된 메모리 역참조 금지


## 구조체
- struct 키워드로 다른 데이터 형식 여러 개를 묵어 하나의 커스텀 데이터 형식 만듦


## 정적 변수
- 지역변수 : 스택영역
- 동적 할당 변수 : 힙영역
- 전역 변수, 정적 변수 : 데이터 영역

데이터 영역은 프로그램이 시작할 때 할당되며 종료할 때 해제됨


## 레퍼런스 변수
- 변수명 앞 & 를 사용해 원본 변수를 참조
- 변수에 & 를 붙인 별칭을 부여
- 참조에 의한 호출 call by reference

### 레퍼런스와 포인터의 차이
- 레퍼런스의 기능은 포인터로도 가능
- 레퍼런스는 포인터를 비교적 안전하게 사용할 수 있도록 만든 도구
- 포인터처럼 원본 값에 접근할 수 있지만, 원본 자체나 공간의 크기, 메모리 주소 등은 변경하지 못하게 막은 것
- 스마트 포인터도 같은 맥락
